# Inquisia Frontend Agent Instructions

This repository contains the frontend for Inquisia, an AI-powered academic project management platform.

Stack:
- Next.js
- TypeScript
- Tailwind CSS
- Component-driven UI

Rules:
- Preserve the existing folder structure where possible.
- Make incremental changes only.
- Do not rewrite the whole project unless strictly necessary.
- Keep all pages and components production-readable.
- Prefer reusable components over duplicated code.
- Keep UI clean, modern, and admin-dashboard friendly.
- Do not hardcode API base URLs; use environment variables.
- Maintain role-aware flows for student, supervisor, admin, and public users.
- Elara must be scoped to academic/project-related interactions only.

Before finishing:
- Ensure the app builds successfully.
- Fix imports and broken routes.
- Remove obvious placeholder/template branding if found.
