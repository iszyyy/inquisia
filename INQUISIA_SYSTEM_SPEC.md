# Inquisia System Spec

Roles:
- student
- supervisor
- admin
- public

Core flows:
1. student submits project
2. supervisor reviews and requests revision
3. student resubmits
4. supervisor approves
5. admin publishes
6. public browses published project
7. Elara answers system-aware project/research questions

Elara scope:
- allowed: project workflow, research support, repository search, platform questions
- disallowed: relationships, gossip, unrelated general chat

Primary statuses:
- draft
- submitted
- under_review
- revision_requested
- resubmitted
- approved
- published
- rejected
